# Shipment-price-prediction-ML-Project-


### This project focuses on predicting shipment prices using machine learning techniques. The goal is to develop a model that can accurately estimate the cost of shipping based on various factors such as distance, weight, dimensions, and other relevant features.
### The project involves several key steps, including data collection, preprocessing, feature engineering, model selection, training, and evaluation. The dataset used for this project may include historical shipment data, which can be sourced from logistics companies or public datasets.
### The machine learning model can be trained using algorithms such as linear regression, decision trees, random forests, or gradient boosting. The performance of the model will be evaluated using metrics such as mean absolute error (MAE), mean squared error (MSE), or R-squared.
### The ultimate aim of this project is to provide a reliable tool for logistics companies to estimate shipment prices, which can help in budgeting, pricing strategies, and improving overall efficiency in the shipping process.   

## HOW TO RUN 
Before you run this project,make sure you have MongoDB Atlas account and you have the shipping dataset into it. Then, you can run the project by following these steps:
1. Clone the repository to your local machine.
```
   git clone https://github.com/mijan3/Shipment-price-prediction-ML-Project-.git
```
2. Create a conda environment and install the required dependencies.
```
   conda create -n shipment-price-prediction python=3.11
   conda activate shipment-price-prediction
   pip install -r requirements.txt
```
